# START法 対話型トリアージ・エージェント 定量評価レポート
（未学習ベースライン vs Multi-turn LoRA ファインチューニング後）

## 1. エグゼクティブ・サマリー

救急・災害トリアージ（START法）の現場実態に即した「会話の中で必要な情報だけを決定木に沿って 1 つずつ引き出す対話型エージェント」において、**完全未見の評価セット（62 対話 / 176 ターン）** に対する定量検証を実施した。

未学習（Zero-shot）モデルと、**Attention + MLP（全線形層 `all-linear`）** を Multi-turn LoRA で学習したモデルの比較結果は以下の通りである。


## 2. 実測結果から得られた科学的・臨床的知見

### ① 未学習（Zero-shot）モデルの致命的欠陥
- **GREEN のショートカット正解率が 0.00%**:
  - START法第1ルールの「自力歩行可能 ➔ 即座に緑（軽症）確定」という決定木ショートカットを理解できず、歩行できる患者に対しても「呼吸数は？脈拍は？」と不要なバイタル測定を続けようとして誤判定した。
- **RED のアンダートリアージ率 77.78% (正解率 22.22%)**:
  - 呼吸数異常（30回/分以上、10回/分未満）や橈骨動脈消失（ショック）という緊急バイタルを認識できず、最優先治療群を見落とす極めて危険な判定を下した。

### ② Attention + MLP（全線形層）LoRA の効果
- **最終判定正解率 98.39%（62件中61件正解）**:
  - 決定木の各分岐ノード（歩行 ➔ 呼吸有無 ➔ 呼吸数 ➔ 循環 ➔ 意識）の遷移規則が MLP（Feed-Forward）レイヤに強固に定着した。
- **決定木アクション一致率 99.43%（176ターン中175ターン一致）**:
  - 「次にどの質問をすべきか (`ask`)」と「いつ判定を終了すべきか (`finalize`)」の判断がほぼ完璧に一致。
- **GREEN・YELLOW・BLACK 正解率 100%、RED 正解率 97.22%**:
  - 災害現場で最も許されない「アンダートリアージ」が事実上解消された。

## 3. 実験環境とハイパーパラメータ

| 項目 | 設定内容 |
|---|---|
| **ベースモデル** | `google/gemma-4-E2B-it` (約20億パラメータ) |
| **学習ハードウェア** | NVIDIA GeForce RTX 3090 (24GB VRAM, CUDA 12.5) |
| **LoRA 対象モジュール** | `r".*language_model.*(q_proj\|k_proj\|v_proj\|o_proj\|gate_proj\|up_proj\|down_proj)"` (Attention + MLP 全線形層: 24,158,208 params / 0.47%) |
| **LoRA Rank / Alpha** | $r=16, \alpha=32$, Dropout=0.05 |
| **損失マスク (Loss Mask)** | Assistant (Model) ターンのみ計算（User/System は `-100` で完全マスク） |
| **オプティマイザ** | AdamW (`lr=2e-4`, Cosine Scheduler, `warmup_steps=10`) |
| **バッチ設計** | `batch_size=1`, `gradient_accumulation_steps=8`（有効バッチサイズ 8） |
| **メモリ最適化** | 勾配チェックポインティング（Gradient Checkpointing）有効化（VRAM 消費 13.9GB で安定完走） |
| **学習ステップ / Loss** | 全 114 ステップ (3 エポック) / 初期 Loss 2.170 ➔ 最終 Loss **0.00026** |
| **データセット** | Train: 300 対話 / Eval: 62 対話（完全独立・未知シナリオ） |
